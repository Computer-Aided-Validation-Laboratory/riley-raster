Examples
==========================

Riley provides a series of capability demos in Zig and Python. 
For example, render the rabbits demo with:

      .. code-block:: bash

          zig build demo2a-rabbits-mono -Doptimize=ReleaseFast

The equivalent Python demo is:

      .. code-block:: bash

          python -m riley demo2a_rabbits_mono

Browse the `complete Zig demo <https://github.com/Computer-Aided-Validation-Laboratory/riley-raster/tree/main/src>`_ directory or `Python demo directory <https://github.com/Computer-Aided-Validation-Laboratory/riley-raster/tree/main/src/riley/pydemos>`_.
