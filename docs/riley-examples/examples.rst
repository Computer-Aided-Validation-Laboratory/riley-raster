Examples
========

Riley provides runnable demos in Zig and Python. For example, render the
rabbits demo from the repository root with:

.. code-block:: bash

   zig build demo2a-rabbits-mono -Doptimize=ReleaseFast

The equivalent Python demo is:

.. code-block:: bash

   python -m riley demo2a_rabbits_mono

Browse the `Zig demo directory <https://github.com/Computer-Aided-Validation-Laboratory/riley-raster/tree/main/src>`_
or the `Python demo directory <https://github.com/Computer-Aided-Validation-Laboratory/riley-raster/tree/main/src/riley/pydemos>`_.
