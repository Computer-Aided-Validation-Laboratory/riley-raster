Render configuration
====================

Use :class:`riley.RasterConfig` for rendering controls, including input
validation via :class:`riley.ValidateInput`. Camera geometry and saved image
settings are configured with :class:`riley.Camera` and :class:`riley.ImageSaveOpts`.
