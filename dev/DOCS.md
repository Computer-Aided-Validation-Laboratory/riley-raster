# Building Documentation

Riley documentation is composed of two parts:
1. **Zig API Documentation**: Generated directly by the Zig compiler from doc-comments in Zig source files.
2. **Python API Documentation**: Generated by Sphinx using the `shibuya` theme and autodoc/napoleon extensions.

These two documentation suites are merged so that the Zig API documentation is accessible directly under `/zig-api` within the unified Sphinx site.

---

## 1. Prerequisites

- **Zig 0.16.0**: Available on your system `PATH`.
- **Python >= 3.11**: Installed in a virtual environment (e.g., `.venv`).

---

## 2. Installing Documentation Dependencies

Documentation dependencies (`sphinx` and `shibuya`) are defined in [pyproject.toml](file:///home/lloydf/riley-raster/pyproject.toml) under both `[project.optional-dependencies]` (`docs`) and `[dependency-groups]` (`docs`).

### Using `uv` (Recommended)

To install or sync documentation dependencies in your `.venv` virtual environment:

```bash
# If using uv pip in an active venv:
uv pip install -e ".[docs]"

# Or using uv sync:
uv sync --extra docs
```

### Using standard `pip`

```bash
# Activate your virtual environment first
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install with docs optional dependencies
pip install -e ".[docs]"
```

## 3. Step-by-Step Build Instructions

Follow these steps from the root of the repository:

### Step 1: Build Zig documentation

Run the Zig build docs step:

```bash
zig build docs
```

This generates the Zig documentation and interactive standard library/API viewer in `zig-out/docs/`.

### Step 2: Build Python documentation

Ensure your virtual environment is active (or call Sphinx via `.venv/bin/sphinx-build`), then build the HTML documentation:

```bash
sphinx-build -b html docs build/_build/html
```

*(Alternatively, without activating: `.venv/bin/sphinx-build -b html docs build/_build/html`)*

### Step 3: Merge Zig docs into the Python docs

Copy the generated Zig documentation into the `zig-api` subdirectory of the Sphinx build output:

```bash
cp -r zig-out/docs build/_build/html/zig-api
```

*(On Windows PowerShell: `Copy-Item -Recurse -Force zig-out/docs build/_build/html/zig-api`)*

### Step 4: Preview on a local server

Start a local HTTP server to view the unified documentation site:

```bash
python -m http.server 8000 -d build/_build/html
```

Open [http://localhost:8000](http://localhost:8000) in your browser. The Zig API documentation is accessible via the "Zig API documentation" link on the home page or directly at [http://localhost:8000/zig-api/](http://localhost:8000/zig-api/).
